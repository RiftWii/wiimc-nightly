# WiiMC nightly

Daily builds of [WiiMC](https://github.com/dborth/wiimc) from its newest
commit, for [RiftWii's app store](https://github.com/RiftWii/apps). A build
is made only when upstream has changed, and each one is a release with its
own tag and the exact source it was built from.

These are not official releases. Problems with WiiMC itself belong
upstream: https://github.com/dborth/wiimc/issues
